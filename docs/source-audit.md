## Décision vérifiée
L'accès public n'établit pas les droits de redistribution. Aucun connecteur distant n'est suffisamment validé pour activation. L'import JSON/CSV normalisé est la seule entrée opérationnelle ; validation locale, aucune requête réseau vers ces sources. Les choix de licence déclarés dans un import sont des déclarations de l'utilisateur, pas une expertise juridique ou une vérification externe. Une URL HTTPS n'atteste pas l'authenticité d'une note.
