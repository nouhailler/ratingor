# Plan et jalons

1. Audit du dépôt et des huit sources, modèle et architecture : terminé avant codage ; pas de connecteur distant autorisé par les preuves disponibles.
2. Socle React : tableau de bord, catalogue filtrable, fiche et comparaison avec états vides.
3. Modèle immuable, dérivation des séries et corrections/retraits.
4. Import JSON/CSV strict, aperçu, doublons, confirmation partielle, export conditionné aux droits.
5. IndexedDB, favoris/listes, préférences et cache PWA.
6. Adaptateurs : import local opérationnel, sources distantes explicitement désactivées.
7. Tests unitaires, intégration et parcours navigateur, compilation puis bilan factuel.
8. Documentation et interface accessible responsive.
9. Build statique prêt à héberger ; déploiement HTTPS réel à vérifier sur la plateforme choisie, sans le déclarer effectué.
